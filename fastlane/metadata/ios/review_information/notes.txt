Miras uses location only while a trip is active so the customer can track the driver. Camera and photo library are used for driver documents and delivery photos.

Sign-in is live Saudi mobile OTP via Firebase Phone Auth. There is no static demo account and no mock OTP.

1. Open the app → Log in or Register → Customer or Driver
2. Accept Terms
3. Enter a real Saudi mobile number (05xxxxxxxx)
4. Enter the SMS one-time code sent to that number

Admin login is at /admin/login and is limited to allowlisted staff numbers. Real users and production domains (https://hamula-cfc6c.web.app) use the same OTP flow.

Payments go through Moyasar hosted checkout. Callback: https://hamula-cfc6c.web.app/payment-callback
